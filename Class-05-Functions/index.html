PaisaPay v5: fee, cashback and modes come back

PaisaPay v5 · build 2 of 4
Three small helpers return a number or a name. pay uses them. mode has a default.
def fee_for(mode):
    if mode == "card":
        return 5
    elif mode == "netbanking":
        return 2
    return 0

def cashback_for(amount):
    if amount >= 5000:
        return 100
    elif amount >= 2000:
        return 50
    elif amount >= 500:
        return 10
    return 0

def mode_name(mode):
    match mode:
        case "upi":
            return "UPI"
        case "card":
            return "Card"
        case "netbanking":
            return "Net banking"
        case _:
            return "Unknown mode"

def pay(balance, payee, amount, mode="upi"):
    fee = fee_for(mode)
    if amount + fee > balance:
        print("Insufficient balance. Payment refused.")
        return balance
    cashback = cashback_for(amount)
    print("Paid ₹", amount, "to", payee, "via", mode_name(mode))
    print("Fee ₹", fee, "| Cashback ₹", cashback)
    return balance - amount - fee + cashback

balance = 1000
balance = pay(balance, "Chai Point", 600)
balance = pay(balance, "Zomato", 300, mode="card")
Paid ₹ 600 to Chai Point via UPI Fee ₹ 0 | Cashback ₹ 10 Paid ₹ 300 to Zomato via Card Fee ₹ 5 | Cashback ₹ 0
  • Every return in pay hands back a balance, refused or not. The caller always stores it.
  • The v3 if / elif chains and the match did not change. They got names.

memory = ["hello", "PIN=4321", "KEY=secret99"]

  • One line at the door: if count != 1: return. Send back only what was sent in.
Real incident · 2014

The same mistake at internet scale: Heartbleed

  • OpenSSL, the code behind the padlock on most websites, had a “heartbeat” function: send some text and its length, get the same text back.
  • It never checked that the length matched the text. Ask for 64,000 bytes with a 1-byte message, and it sent back 64,000 bytes of whatever was in memory: passwords, keys.
  • Disclosed April 2014. About 17% of the internet's secure servers, around half a million, were open to it.
A function must not trust its arguments. Validate at the boundary.
Read: Heartbleed · heartbleed.com
