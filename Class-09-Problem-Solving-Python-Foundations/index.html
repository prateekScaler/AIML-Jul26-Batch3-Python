  • A list answers "what is at position 2?". A dictionary answers "what is stored under age?".

Add a key, update a key, ask safely

student["city"] = "Pune"

print(student)

✋
There is no "grade" key. Does the second line crash?
print(student.get("age"))

KeyError
21 then None
21 then an empty string

  • get is the safe lookup: None when the key is missing, or a default you choose: student.get("grade", "Not assigned").

keys, values, items, update, pop

student = {"name": "Akshay", "age": 20}

print(student.keys())
print(student.values())
print(student.items())
dict_keys(['name', 'age']) dict_values(['Akshay', 20]) dict_items([('name', 'Akshay'), ('age', 20)])
  • items() gives pairs, and each pair is a tuple. Tuples again.
student.update({"age": 22, "grade": "A"})
print(student)

removed = student.pop("grade")
print(removed)
print(student)
{'name': 'Akshay', 'age': 22, 'grade': 'A'} A {'name': 'Akshay', 'age': 22}
  • update: several keys at once. pop: remove a key and hand back its value.

Industry practice

JSON does the same thing, quietly

  • An LLM or an API returns JSON. Python's json.loads turns it into a dictionary.
  • If the JSON repeats a key, Python keeps the last value and drops the rest. No error.
  • '{"x": 1, "x": 2, "x": 3}' becomes {'x': 3}.
The silent overwrite you just saw is also how every JSON object enters your program. Validate what an agent sends before you trust it.

Looping over a tuple and a set

    print(value)

Quick-fire: same box or new box?

What prints?
a = [1, 2, 3]
b = a
b.append(4)
print(a)
[1, 2, 3, 4]. b = a does not copy. Two names, one list. Append through either name and both see it. A copy is b = a[:].
A tuple holding a list. What prints?
t = (1, 2, [3, 4])
t[2].append(5)
print(t)
(1, 2, [3, 4, 5]). The tuple did not change: slot 2 still holds the same list. The list is mutable, so it grew. Immutable means the slots are fixed, not that everything inside is frozen.

Concept check: input and loops

The user types 42 at an input() prompt. What does the program hold?
The string "42". Always text. int() converts it, and crashes on "abc" until Class 12 teaches errors.
How many numbers does this print?
for i in range(1, 10, 3):
    print(i)
3. 1, 4, 7. The next would be 10, and 10 is the stop, excluded.

Concept check: functions and lists

What prints?
def double(x):
    print(x * 2)

result = double(5)
print(result)
10 then None. The function prints 10 and returns nothing, so result is None. To use a value later, return it.
What prints?

print(sorted(nums), nums)
[1, 2, 3] [3, 1, 2]. sorted makes a new list and leaves the original alone. nums.sort() would change nums and give None.

Concept check: strings and structures

After this, what does text hold?
text = "  hello  "
text.strip()
Still " hello ". strip made a new string and nobody stored it. Write text = text.strip().
Keep every mark for each student, by name, and add marks later. Which structure?
A dictionary of lists. Lookup by name is a dictionary. Many marks per name, growing, is a list under each key. A set would drop a repeated mark; a tuple cannot grow.
