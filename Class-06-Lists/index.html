Revision: where does a variable live?

  • Local: created inside a function. Lives only while that call runs.
  • Global: created outside every function. Any function can read it.
✋

  • Two boxes with the same label, in two different rooms.
What prints?

    return amount * rate // 100

    return amount <= limit

    limit = 1000

Revision: parameters with defaults go last

✋
Two definitions. Which one does Python accept?
def pay(amount, mode="upi"):      # A
    print(amount, mode)

def pay(mode="upi", amount):      # B
    print(amount, mode)
Only A
Only B
Both
SyntaxError: parameter without a default follows parameter with a default
  • Python fills parameters left to right. With B, pay(500) cannot tell whether 500 is the mode or the amount.
  • So the rule: required parameters first, defaults last.
Two rules, two places
WhereRuleGoodRefused
DefinitionRequired first, defaults lastdef pay(amount, mode="upi")def pay(mode="upi", amount)
CallPositional first, keywords lastpay(500, mode="card")pay(mode="card", 500)
Which definition is valid?
The first. Every required parameter sits before every default. The other three put a required one after a default.
A valid definition, four calls. Which call is refused?
def pay(amount, mode="upi", note=""):
    print(amount, mode, note)
The last one. A plain value after a keyword has nowhere to go: SyntaxError. The other three, one by one:
pay(500) → 500 upi both defaults fill in pay(500, "card") → 500 card "card" lands in mode, by position pay(500, note="rent") → 500 upi rent mode skipped, keeps its default; note named
Definition: required, then defaults. Call: positional, then keywords. Same shape, both sides.

When the collection has a limit

Real incident · 2020

Nearly 16,000 COVID cases went missing in England

  • October 2020. Test results were collected into Excel files in the old XLS format.
  • That format holds about 65,000 rows. Each result took several rows, so each file held about 1,400 cases.
  • Everything past the limit was silently dropped. Contacts of those cases were never traced.
A Python list grows as you append. A fixed-size container drops the rest, and says nothing.
Read: BBC: why using Excel caused Covid-19 results to be lost
  • How big can a Python list get? There is no fixed size. len can go up to sys.maxsize: 9,223,372,036,854,775,807 boxes on a 64-bit machine.
  • Memory runs out long before that. The limit is your RAM, not the list.

# PaisaPay v6: the app remembers
print("Welcome to PaisaPay")

saved_pin = "4321"
history = []

def is_valid_amount(amount):
    return amount > 0 and amount <= 100000

def is_valid_pin(pin):
    return pin == saved_pin

def fee_for(mode):
    if mode == "card":
        return 5
    elif mode == "netbanking":
        return 2
    return 0

def cashback_for(amount):
    if amount >= 5000:
        return 100
    elif amount >= 2000:
        return 50
    elif amount >= 500:
        return 10
    return 0

def mode_name(mode):
    match mode:
        case "upi":
            return "UPI"
        case "card":
            return "Card"
        case "netbanking":
            return "Net banking"
        case _:
            return "Unknown mode"

def show_balance(balance):
    print("Balance: ₹", balance)

def add_money(balance, amount):
    if not is_valid_amount(amount):
        print("Invalid amount. Nothing added.")
        return balance
    print("Added ₹", amount)
    return balance + amount

def ask_pin():
    for attempt in range(3):
        pin = input("UPI PIN: ")
        if is_valid_pin(pin):
            return True
        print("Wrong PIN.", 2 - attempt, "attempts left")
    return False

def pay(balance, history, payee, amount, mode="upi"):
    if not is_valid_amount(amount):
        print("Invalid amount. Payment refused.")
        return balance
    if mode_name(mode) == "Unknown mode":
        print("Unknown payment mode. Payment refused.")
        return balance
    fee = fee_for(mode)
    if amount + fee > balance:
        print("Insufficient balance. Payment refused.")
        return balance
    cashback = cashback_for(amount)
    print("Paid ₹", amount, "to", payee, "via", mode_name(mode))
    print("Fee ₹", fee, "| Cashback ₹", cashback)
    history.append(amount)
    return balance - amount - fee + cashback

def mini_statement(history):
    if len(history) == 0:
        print("No payments yet.")
        return
    total = 0
    for amount in history:
        total += amount
    print("Payments:", len(history), "| Spent ₹", total)
    print("Biggest ₹", sorted(history)[-1])
    print("Last five:", history[-5:])
    big = [amount for amount in history if amount >= 500]
    print("Big payments:", big)

choice = ""
