A student writes this. What happens?
is_paid = true
NameError: name 'true' is not defined.
  • Python works out the right side first.
  • true has no quotes, so it is a name. Python goes looking for a variable called true, to copy its value.
  • No such variable exists. So it stops.
  • a = b only works when b already has a value. Only True, capital T, is the built-in boolean.

= does not mean “equals”

🎤
In maths, = means “is equal to”. In Python, does age = 25 mean the same thing?
age ← 25
  • age = 25 means: store 25 under the name age.
  • An action. Not a claim that two things are equal.
✋

Prints 20 and 21
