Real incident · 2008

Every Zune 30 froze on the same day

  • 31 December 2008: thousands of Microsoft Zune music players stopped at once.
  • The clock code had a while loop. On day 366 of a leap year, nothing inside it changed the day count.
  • The loop ran until the day was over. The fix: wait for 1 January.
days = 366        # 31 December 2008, day 366 of a leap year
leap = True

while days > 365:
    if leap:
        if days > 366:      # 366 is not more than 366
            days -= 366      # so this never runs
    else:
        days -= 365
Every while needs a line that moves it towards False. On every path. Every time.
Read: Zune bug explained in detail · Zune 30
This one does change the balance. Does it stop?
balance = 1000

while balance != 0:
    balance -= 300
    print("Left:", balance)
Never. 1000 → 700 → 400 → 100 → −200 → … It jumps over 0, so != 0 stays True. Changing the variable is not enough. The condition must become False. Safer: while balance >= 300.

for or while?

  • for: you know the sequence or the count.
  • while: you know the stopping condition.

Real incident · 1990

The same mistake took down half of America's long-distance calls

  • 15 January 1990. AT&T's 114 switches crashed and restarted each other in a chain.
  • The cause: a break inside an if, which left a bigger block than the programmer intended.
  • Nine hours. About half of all calls failed. Over 50 million calls blocked, over $60 million lost.
Know exactly which block a break leaves. Indentation tells you.

Same idea with while. What happens?
count = 0

while count < 5:
    if count == 3:
        continue
    print(count)
    count += 1
Stuck. At 3, continue jumps back to the condition and skips count += 1. In a for loop, range moves on by itself. In a while loop, moving on is your job.

pass: do nothing, for now

for i in range(5):
    if i == 3:
        pass
    else:
        print(i)
0 1 2 4
StatementEffect
breakLeave the whole loop.
continueSkip the rest of this pass. Next pass.
passNothing. A placeholder where Python needs a line.

0 1 2. pass does nothing, then Python continues to print(i). With continue in its place: 0 2.

Nested loops draw grids

for row in range(3):
    for column in range(3):
        print("*", end=" ")
    print()
* * * * * * * * *
  • Outer loop: rows. Inner loop: columns.
What is end=" " doing?
  • Every print ends with something. The default is a new line: end="\n".
  • end=" " ends with a space instead. The next print continues on the same line.
  • Without it, the inner loop prints one star per line: nine lines, no grid.
  • The bare print() prints nothing, then its default end: the new line that finishes the row.
print("Chai", end=" | ")
print("Point")
Chai | Point
The inner range now depends on the row. What shape prints?
for row in range(1, 4):
    for column in range(row):
        print("₹", end=" ")
    print()
Growing triangle. row is 1, 2, 3. range(row) gives that many values. The inner loop may use the outer loop's variable.

Recap

for — walk through a sequence. range(start, stop, step), stop excluded.
while — repeat while a condition is True. Set the variable before, change it inside.
break / continue / pass — leave the loop, skip one pass, do nothing.
nested loops — the inner loop runs fully for each outer pass.
patterns — accumulate, count, find, filter. Start the variable above the loop.
