The fix, part 2: methods are the door

  • Methods live inside the class, so they can use self.__balance. Outside code calls them.
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
✋

  • Two leading underscores say: internal, change it only through the methods.

Does the double underscore lock the door?

What does the double underscore actually do to __balance?
Renames it. The value is stored under _BankAccount__balance, so a plain outside read finds nothing.
✋

  • So a programmer can still bypass it with the longer name. A speed bump, not a lock: a strong "do not" to other programmers.
  • Abstraction is the other half: whoever calls deposit(50) does not need to know the rule inside or how the balance is stored. A simple name hides the work.
  • Encapsulation hides the data. Abstraction hides the steps.

What problems does regex solve?

  • Text that has a pattern. A regular expression does three jobs on it.
  • Why it matters: forms, logs, bank messages and files are full of such text.
  • It works in Python, JavaScript and Java, and in your editor's find box.
  • It is free and fast, and it runs on your own machine.

print(bool(re.search(r"\W", "a_1")))
print(bool(re.search(r"\S", "   ")))
False False False
  • Each one looks for what the text does not have.
\D is not a digit, \W is not a word character, \S is not a space.
Where this helps: Pull out an ID. \S+@\S+ takes sumit@ybl out of "Pay sumit@ybl today": no spaces on either side of the @.

Capturing groups: keep the pieces you want

  • Brackets in the pattern mark a piece. The match gives it back by number.
text = "Name: Rex, Age: 3"
match = re.search(r"Name: (\w+), Age: (\d+)", text)

print(match.group(0))
print(match.group(1))
print(match.group(2))
✋
Three prints. What are they?
The whole match, then Rex, then 3
Rex, then 3, then an error
Name, then Age, then the whole match
Name: Rex, Age: 3 Rex 3
  • group(0) is the whole match. group(1) and group(2) are the first and second brackets, in order.
  • The pattern describes the whole shape; the brackets say which pieces to keep.

findall with groups: a list of tuples

The pattern has two groups. What does findall return?
text = "Name: Rex, Age: 3; Name: Fido, Age: 5"
pairs = re.findall(r"Name: (\w+), Age: (\d+)", text)
print(pairs)
A list of tuples. With groups in the pattern, findall returns one tuple per match holding only the groups. Class 8's tuples, one per record. Surprising the first time: test it, do not assume.

PaisaPay v13: a UPI ID check, a PAN check, and reading a bank SMS

PaisaPay v13 · build 3 of 3
Three shapes, three patterns. The old UPI check split on @ and counted parts; now the pattern says exactly what is allowed.
import re

def is_valid_upi_id(upi_id):
    return re.fullmatch(r"[a-z0-9.]+@[a-z]+", upi_id) is not None


def is_valid_pan(pan):
    # five letters, four digits, one letter: ABCDE1234F
    return re.fullmatch(r"[A-Z]{5}\d{4}[A-Z]", pan) is not None


def read_bank_sms(sms):
    # "Rs.600 debited from a/c XX4321 to SUMIT on 04-11-26 via UPI"
    m = re.search(r"Rs\.(\d+) debited from a/c XX(\d{4}) to (\w+)", sms)
    if m is None:
        return None
    amount, tail, payee = m.groups()
    return int(amount), tail, payee.title()
Choose: 6 Paste the bank SMS: Rs.600 debited from a/c XX4321 to SUMIT on 04-11-26 via UPI ₹600 to Sumit from the account ending 4321 Choose: 7 PAN: ABCDE1234F Valid PAN
  • fullmatch for a whole field, search plus groups for pulling pieces out of a message.

Mini project: read a server log

  • A log line is text with a shape: a timestamp, a level, a message. Every idea today in one pattern.
import re

logs = [
    "2026-11-04 21:05:02 ERROR Failed to connect to database",
    "2026-11-04 21:05:05 INFO Retry succeeded",
    "2026-11-04 21:06:40 WARNING Disk usage above 90%",

pattern = r"(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) (\w+) (.+)"

for line in logs:
    timestamp, level, message = re.match(pattern, line).groups()
